MovieExplorer

A responsive movie discovery app built with React and the TVMaze API. Search for shows, browse a card grid, and open a details modal for ratings, genres, and summaries.

Built for the Apollo Level 2 Web Dev program, Next-Level Foundation assignment.

Features
Home page — hero banner with a call-to-action into the movie listing
Movie listing page — live search bar that queries the API as you type, with a responsive card grid (1 column on mobile, up to 4 on desktop)
Movie cards — poster, title, release year, and rating
Details modal — backdrop image, rating, release date, genres, network, and full summary; closable via the ✕ button or by clicking outside
Fully responsive layout across mobile, tablet, and desktop
Tech stack
React 19 + Vite
React Router for client-side routing
Tailwind CSS 4 for styling
lucide-react for icons
TVMaze API for show data
